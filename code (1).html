🗑 Zona de contenção

1. Navegador

  • Digite a URL e ➤ IR. Espelhos e atalhos prontos acima.
  • 📋 COPIAR copia o texto integral da página carregada; se o site bloquear leitura (Same-Origin Policy), copia a URL e avisa.
  • 📸 PRINT captura o app inteiro em PNG. Para capturar o conteúdo do iframe quando ele carregar via Wayback/proxy, use o print nativo do celular (o botão abre o snapshot em aba nova quando necessário).

2. Iframe Wall

  • Snapshots históricos do Wayback Machine (estratégia archive.org original).
  • Densidade 12/24/48; toque na célula para expandir no visualizador.

3. Terminal / OSINT

  • Comandos: nmap, whois, dig, sub, geo, ports, archive, help, clear.
  • Consultas saem para APIs públicas (hackertarget, Google DNS, crt.sh, wayback) — não consulte alvos sigilosos por aqui; use o Kali local.

4. Banco

  • Entradas de texto/link/imagem/áudio/vídeo/arquivo, com tags, classificação SCP e senha por entrada.
  • 📋 Copiar copia o texto integral; ✏ Editar registra a versão anterior em 📜 VERSÕES.

5. Cofre

  • Defina a mestra (mín 8). Senhas cifradas AES-GCM/PBKDF2. Revelar/copy exigem a mestra.

6. Backup

  • Export/Import/Merge JSON + snapshot + console de diagnóstico.

⚠️ Uso somente em sistemas próprios ou com autorização por escrito. Uso não autorizado é ilegal.
